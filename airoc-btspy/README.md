# AIROC BTspy Converter

This converts the textual HCI log from AIROC's Bluetooth tools into a PacketLogger HCI trace.

More info: https://community.infineon.com/t5/Blogs/Bluetooth-Spy-BTSpy-The-Bluetooth-protocol-sniffer-from-Infineon/ba-p/719974

Usage:

	$ cd btspy
	$ ./btspy_to_pklg.py filename.txt
